# Безопасность

Сообщить об уязвимости: catacode@yandex.ru. Не присылайте действующие ключи,
токены, персональные данные или дампы. Укажите версию и минимальный пример.
Обычные вопросы без секретов можно оформлять в публичных Issues. Описание
уязвимости, позволяющей атаковать установку, сначала отправляйте на email.

Плагин выполняется с полномочиями процесса Paperclip. Разрешенные каналы и
пользователи задаются точными ID. Это доверенная внутренняя команда, а не
система изоляции клиентов или замена корпоративного управления доступом.

Авторизация Mattermost не связывается автоматически с пользователем Paperclip.
Отзыв доступа: убрать ID из allowedUserIds, сохранить конфигурацию; отдельно
остановить ранее запущенные задачи и отозвать нужные токены. Исключение из
чата не отменяет внешний процесс. Не добавляйте клиентские каналы в общую
установку без отдельного анализа прав и памяти.

Бот с ручным подключением получает чтение разрешенных каналов, публикацию
сообщений и реакции. Автоматическое создание профилей дополнительно требует
высоких прав администратора Mattermost. По возможности используйте ручной
режим. Токены автоматических профилей шифруются AES-256-GCM, ключ хранится
через отдельный secret_ref; потеря ключа делает сохраненные токены нечитаемыми.

Содержимое запросов отправляется агенту и выбранному поставщику модели,
ответ публикуется в исходной ветке. Данные и состояние хранятся Paperclip
и Mattermost по их политике хранения. Плагин не содержит аналитики, рекламных
или телеметрических отправок. Это не отключает телеметрию самого хоста.

Секреты не передаются в query URL, перенаправления REST запрещены, HTTPS
обязателен. HTTP допускается только для явно включенного локального режима.
Новые разрешения манифеста проверять при обновлении, не подтверждать вслепую.
