# Разработка и сопровождение

Поддерживаемый первый диапазон: Paperclip 2026.1023.0, SDK 1.0.0 и
Mattermost Team Edition 11.7.14. Другие версии требуют проверки. SDK пока alpha.

```sh
npm ci
npm run check
npm test
npm run build
npm pack --dry-run
```

Для тестов SDK не нужен: тестируются отдельные модули и адаптеры контекста.
Для реального запуска worker нужен SDK из установленного Paperclip, см. README.
Тесты не обращаются к рабочим сервисам. Проверку взаимодействия проводить на
разрешенном стенде с отдельными учебными сообщениями, после нее их удалять.

Обязательные проверки: разрешенные и запрещенные авторы/каналы, тред,
редактирование упоминания, повтор события, ошибка модели, ошибка доставки,
перезапуск, ручные и управляемые профили, сохранение состояния при обновлении.
Галочка означает доставку ответа, а не независимое подтверждение его качества.

Одна правка должна менять один контракт. При новом действии документировать
необходимые права, хранение данных и поведение при ошибке. Не вводить
автоматическую передачу старому механизму без явного решения.

Версии package.json и manifest.js совпадают. Для выпуска изменить обе версии,
обновить CHANGELOG, выполнить проверки и приемку на стенде, создать тег v<version>.
GitHub Actions проверяет архив; выпуск формируется оператором только после
успешного CI. npm publish запрещен полем private до отдельного решения.
Исходники и пакеты распространяются через приватный GitHub Releases.

Перед предложением в Paperclip сначала проверить связанные публичные issues/PR
и согласовать крупный интерфейс. Предложение расширения SDK отделять от
реализации плагина. Не копировать внутренние ссылки, идентификаторы и данные
компании в публичный PR. Требования разработчиков:
https://github.com/paperclipai/paperclip/blob/v2026.1023.0/CONTRIBUTING.md.
