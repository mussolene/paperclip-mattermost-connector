# Изменения

## 0.3.0-beta.1

- Отдельный пакет MIT на основе действующего коннектора.
- Сохранены вопросы без задачи, поручения, треды, отредактированные упоминания,
  реакции состояния, предварительная оценка и автоматические профили.
- Добавлена строгая проверка URL, обязательных параметров и повторных ID.
- Убрано обязательное обращение к npm за недоступной версией SDK: используется
  проверенный SDK хоста с явной командой подключения.
- Добавлены документация, примеры без секретов, CI и проверка выпуска.
- Область поддержки ограничена указанными версиями. Полное соответствие
  штатному Slack и нативная привязка пользователей не заявляются.
