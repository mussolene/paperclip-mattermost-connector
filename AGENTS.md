# Разработка коннектора

- Только стандартный SDK плагинов Paperclip. Ядро и сторонние плагины не менять.
- Сначала читать README.md, docs/ARCHITECTURE.md и docs/SLACK-PARITY.md.
- MIT. Сохранять сведения о происхождении и лицензиях зависимостей.
- Проверять компанию, канал и автора до получения секретов и вызова агента.
- Секреты только через secret_ref. Не добавлять токены, ключи, переписку и
  рабочие ID в примеры, тесты или Git.
- Не заявлять полное соответствие Slack или изоляцию клиентов по инструкциям.
- Перед коммитом npm run check, npm test, npm run build и git diff --check.
- Conventional Commits с русским описанием. Без длинных тире.
- OACS является памятью проекта; не создавать параллельные файлы памяти.
- Владелец явно разрешил публичный доступ к этому репозиторию после проверки.
  Публиковать здесь только общий коннектор MIT. Закрытые проекты компании,
  рабочие конфигурации и доступы сюда не переносить. Перед отправкой проверять
  историю и артефакты на секреты. Отправка PR в Paperclip, npm publish и
  дальнейшее изменение видимости требуют отдельного прямого поручения.
- После работы удалять свои временные артефакты, сохраняя базы и ключи.
