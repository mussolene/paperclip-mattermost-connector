# Mattermost Connector for Paperclip

Самостоятельный плагин MIT для общения с агентами Paperclip через Mattermost.
Не требует патча ядра Paperclip. Первый отдельный выпуск: **0.3.0-beta.1**.

## Возможности

- Вопросы и консультации без создания задачи.
- Поручения с отдельной задачей Paperclip и необязательной предварительной оценкой.
- Ответы в исходной ветке, продолжение консультации без нового упоминания.
- Обработка добавленного при редактировании упоминания и защита от дублей.
- Реакции ⏳ при принятии, ✅ после доставки, ⚠️ при ошибке.
- Один профиль Mattermost для каждого агента; ручное или автоматическое подключение.
- WebSocket для быстрого приема и сверка раз в минуту для задач и пропущенных событий.
- HTTPS, разрешенные каналы/авторы и ссылки на секреты Paperclip.

Примеры:

```text
@assistant вопрос: Как устроен процесс проверки?
@assistant задача: Проверь документацию и подготовь отчет, ничего не публикуй.
@assistant поисследуй варианты решения и приведи первичные источники.
@assistant агенты
```

Используйте имя бота из своей установки. Без явного поручения неоднозначная
реплика остается консультацией. Качество результата проверяет сотрудник:
галочка означает только доставку ответа. Консультационный запрет изменений
задан инструкциями модели, это не отдельная техническая песочница.

## Совместимость и ограничения

Проверяемая основа: **Paperclip 2026.1023.0, SDK 1.0.0, Mattermost 11.7.14**.
Node.js 24.11 или новее. API плагинов Paperclip пока alpha, поэтому другие
выпуски нельзя считать совместимыми без испытаний.

Одна компания на worker. Статические списки авторов/каналов предназначены для
доверенной внутренней команды. Привязка пользователей Paperclip, свободный
доступ клиентов, штатные личные диалоги и управляемые инструменты Slack не
заявляются. Плагин не заменяет OACS, модель, подписку, runner или систему прав.

[Сравнение с официальным Slack](docs/SLACK-PARITY.md) перечисляет готовое,
отсутствующее и возможные будущие предложения для SDK.

## Установка из исходников

```sh
git clone https://github.com/mussolene/paperclip-mattermost-connector.git
cd paperclip-mattermost-connector
npm ci
npm run check
npm test
npm run build
npm run link-sdk -- /path/to/paperclip/packages/plugins/sdk
```

SDK не входит в архив и не скачивается автоматически. На дату проверки запрос
версии 1.0.0 через npm возвращал 404. Она присутствует в выбранном выпуске
Paperclip; используется его уже собранный SDK. Опциональная peer dependency
означает отсутствие автоматической установки, а не необязательность SDK при
исполнении worker. Команда link-sdk проверяет имя, версию, dist и не заменяет
посторонний каталог. В официальном контейнере проверяемый путь:
`/app/packages/plugins/sdk`. Его исходные зависимости загружаются штатным
loader Paperclip (tsx); прямой `node dist/worker.js` вне хоста не является
поддерживаемым способом запуска. Выполняйте подключение внутри той среды, где
Paperclip будет загружать плагин.

В диспетчере Plugins установите пакет из доступного серверу локального пути
или через CLI:

```sh
paperclipai plugin target
paperclipai plugin install /path/to/paperclip-mattermost-connector
```

Путь должен существовать внутри сервера/контейнера Paperclip. GitHub архив
исходников без сборки не является готовым runtime-пакетом. В GitHub Releases
предоставляется собранный tgz. После распаковки в постоянный каталог выполните
`node scripts/link-sdk.mjs /path/to/paperclip/packages/plugins/sdk`, затем
установите этот каталог. Не используйте каталог с рабочими секретами как пакет.

## Настройка

Начните с [ручного примера](examples/manual.json). Замените все примерные ID.
Создайте собственного бота Mattermost, включите токены и добавьте его в
выбранную команду и каналы. Права: чтение сообщений, публикация и реакции.
Сохраните токен в штатных Secrets Paperclip и укажите только secret_ref.

- companyId: компания, которой принадлежит конфигурация плагина.
- mattermostBaseUrl: HTTPS-адрес Mattermost, допустим путь обратного прокси.
- channelIds: разрешенные каналы. Само добавление бота в канал не разрешает работу.
- allowedUserIds: точные ID сотрудников, которым разрешены поручения.
- bots: соответствия agentId, botUserId, botUsername и ссылки на токен.
- financeAgentId: необязательный агент оценки, которому сначала направляются задачи.

[Автоматический пример](examples/managed.json) требует autoProvisionProfiles,
teamId, profileAdminToken и profileEncryptionKey. Последний секрет должен
содержать случайный 32-байтовый ключ в виде 64 шестнадцатеричных символов.
Ключ не хранить в JSON. Административный режим имеет высокие полномочия:
перед включением прочитайте [SECURITY.md](SECURITY.md).

HTTP разрешается только с allowInsecureLocal=true и точным локальным именем
localhost, loopback или mattermost для сети Docker. Учетные данные, query и
fragment в базовом URL запрещены. Не ослабляйте это ради внешнего HTTP.

## Проверка и эксплуатация

1. Проверьте health и отсутствие ошибок Secrets/прав. Статус ready сам по себе
   не доказывает доступность всех соединений.
2. От разрешенного сотрудника отправьте учебный вопрос, дождитесь ⏳ и ответа с ✅.
3. Продолжите консультацию в той же ветке; затем испытайте отдельное поручение.
4. Проверьте добавленное редактированием упоминание и повтор события без дубля.
5. От запрещенного пользователя или из другого канала работа запускаться не должна.
6. Проверьте ошибку доставки, перезапуск и сохранение задач. Удалите учебные сообщения.

Состояние и настройки принадлежат Paperclip. При обновлении сохраняйте ID
плагина `catacode.paperclip-mattermost`, базу, Secrets и ключ шифрования профилей.
Соберите новую версию, обновите пакет штатной командой Upgrade и проверьте
permissions/health и живой запрос. Не удаляйте состояние ради обновления.
Откат: Disable, возврат прежнего runtime-пакета, Enable и повторная проверка.

Если worker перезапустился посреди консультации, результат активного запуска
не всегда можно восстановить из текущего API сессий. Плагин не запускает его
автоматически второй раз. Перед повторным поручением проверьте старый запуск.
Редактирование уже обработанного сообщения не означает повторное выполнение.
Новая задача в существующем треде остается новой задачей; консультация продолжает
сессию. Полная двусторонняя связь задачи с чатом пока отсутствует.
