# Сторонние материалы и происхождение

## Paperclip и SDK плагинов

Этот проект использует публичный пакет `@paperclipai/plugin-sdk` версии `1.0.0` для исполнения плагина и работы с API Paperclip. Пакет указывается в [package.json](package.json). Сведения об API и поведении встроенной интеграции Slack сверялись с публичным репозиторием Paperclip, тег `v2026.1023.0`, коммит `1b4c803816e82b0265c8422e1a804327a7ed8c54`.

- [Официальный репозиторий Paperclip](https://github.com/paperclipai/paperclip)
- [SDK плагинов в зафиксированном теге](https://github.com/paperclipai/paperclip/tree/1b4c803816e82b0265c8422e1a804327a7ed8c54/packages/plugins/sdk)
- [Лицензия Paperclip](https://github.com/paperclipai/paperclip/blob/1b4c803816e82b0265c8422e1a804327a7ed8c54/LICENSE)

Ссылки на документацию и исходный код использовались как источники фактов при аудите. Реализация Slack из Paperclip в этот проект не копировалась. Упоминание функций Slack не означает, что соответствующие исходные файлы или разрешения Slack включены в этот плагин.

## Mattermost-плагин

Текущий плагин основан на исходной локальной ревизии `ebaf0a4`, извлеченной из ранее существовавшего Mattermost-плагина. В документации и этом файле не приводятся ссылки на закрытый исходный репозиторий или его внутренние пути. Владелец проекта одобрил лицензию MIT для этого проекта. При распространении следует включать применимый текст лицензии и сохранять требуемые уведомления об авторских правах для включенного исходного кода.

## Slack

Slack упоминается только как название внешнего сервиса и встроенной интеграции Paperclip, используемой для сравнения. Этот проект не содержит SDK Slack и не заявляет об аффилированности с Slack Technologies. Ссылки на официальную документацию Paperclip приведены в [SLACK-PARITY.md](docs/SLACK-PARITY.md).
